# Fuentes / Sources

Consulta inicial de S01–S15 / Initial access for S01–S15: **18 October 2026**.
S16–S17 añadidas / added: **28 October 2026**.

Fuentes públicas oficiales de Wolfram para los antecedentes y la comparativa.
Las fechas de versiones son fechas de lanzamiento, con precisión mensual salvo
cuando un anuncio permite indicar el día. La documentación de funciones puede
cambiar después de esta consulta.

dates refer to releases, at monthly precision unless an announcement provides
the day. Function documentation may change after this access date.

## S17

implementation does not include the paper's thermal optimizer.

## Alcance / Scope

Las fuentes documentan capacidades publicadas. No sustituyen un benchmark ni
establecen superioridad o exactitud universal. No se ejecutó una comparación
de resultados con Mathematica. Los objetivos de Mathechan proceden de la
definición del proyecto, no de estas fuentes.

These sources document published capabilities. They do not replace benchmarks
or establish superiority or universal accuracy. No result comparison with
Mathematica was performed. Mathechan's objectives follow from its project
definition, rather than these sources.
