# Mathechan 0.1.1 — operaciones científicas

19 de octubre de 2026 · [English](../../en/releases/0.1.1.md) ·
[Inicio](../../../README.md) · [Historial](../../../CHANGELOG.md)

La versión 0.1.1 amplía el núcleo experimental por consola con nueve operaciones
científicas y correcciones de resultados, dominios y cuadernos. Mantiene SymPy
1.14 como backend y GPL-3.0-or-later. La interfaz gráfica sigue pendiente.

## Descarga y uso

- [Publicación v0.1.1 y archivos](https://github.com/Stochasticboi/Mathechan/releases/tag/v0.1.1).
- [ZIP para Windows x64](https://github.com/Stochasticboi/Mathechan/releases/download/v0.1.1/Mathechan-0.1.1-windows-x64.zip).
- [Código del tag v0.1.1](https://github.com/Stochasticboi/Mathechan/tree/v0.1.1).

Extraiga el ZIP y abra `Mathechan.exe` para iniciar una consola interactiva.
Con argumentos puede ejecutar un cálculo o exportar un gráfico:

```powershell
.\Mathechan.exe 'N[Pi,50]' --json
.\Mathechan.exe 'Sum[n^2,{n,1,10}]'
.\Mathechan.exe 'Solve[x^2==2,x,Reals]'
.\Mathechan.exe 'Plot[Exp[-x^2],{x,-3,3}]' --output gaussian.svg
```

La instalación desde fuentes usa Python 3.11 o posterior y
`python -m pip install -e .`. El paquete expone los mismos cálculos mediante
`python -m mathechan`.
El ZIP de 0.1.0 conserva sus capacidades originales; no recibe estas funciones
por actualizar la documentación o el código de otra versión.

## Nueve operaciones nuevas

| Operación | Ejemplo | Alcance |
|---|---|---|
| `N` | `N[Pi,50]` | Escalar numérico, 1–1000 dígitos significativos solicitados; Float sin racionalización. |
| `Factor` | `Factor[x^2-1]` | Polinomios con coeficientes racionales sobre Q. |
| `Together` | `Together[1/x+1/(x+1)]` | Denominador común en funciones racionales sobre Q. |
| `Cancel` | `Cancel[(x^2-1)/(x-1)]` | Cancelación racional con exclusiones originales conservadas. |
| `Substitute` | `Substitute[x^2+y,x,1/3]` | Sustitución exacta de un símbolo por valor escalar finito. |
| `Sum` | `Sum[n^2,{n,1,10}]` | Suma finita con extremos enteros inclusivos; resultado 385. |
| `Integrate` | `Integrate[Exp[-x^2],{x,-Infinity,Infinity}]` | Integrales definidas o antiderivadas sin constante aditiva. |
| `Solve` | `Solve[x^2==2,x,Reals]` | Ecuación escalar o sistema lineal; conjuntos de soluciones. |
| `DSolve` | `DSolve[{D[y[x],x]==-y[x],y[0]==1},y[x],x]` | Una EDO ordinaria, orden 1 o 2, con datos iniciales opcionales. |

Se añaden listas de hasta 64 elementos e igualdades inertes `==`, sin asignación.
`Solve` usa complejos por defecto y admite `Reals` explícito; los sistemas se
limitan a ocho ecuaciones y variables. `DSolve` permite derivadas `D` anidadas
y datos derivados con `Substitute[D[y[x],x],x,0]==valor`.

El [cuaderno científico](../../../examples/scientific.mchan) contiene las nueve
operaciones como fuentes sin resultados guardados. Abrirlo no ejecuta celdas.

## Resultados y correcciones

- `input` separa una representación reutilizable comprobada de `text`.
  La constante imaginaria se representa mediante `Sqrt[-1]`; `I` sigue siendo
  símbolo genérico. Aproximaciones Float conservan `input: null`.
- `status`, `exact` y `details` añaden diagnóstico. `exact` indica ausencia
  de Float; no certifica completitud. Los conjuntos condicionados, integrales
  pendientes, ramas Piecewise y residuos no verificados permanecen visibles.
- Se conservan restricciones originales de divisiones y potencias negativas;
  sustituciones, términos de sumas y soluciones las transportan o comprueban
  según su alcance. Plot rechaza agujeros encontrados en muestras y comprueba
  extremos simbólicos exactos, como un denominador `Sin[x]` en `Pi`.
- Los cuadernos se escriben como UTF-8 con LF y el límite de 2 MB corresponde
  a los mismos bytes al guardar y abrir, también en Windows. La lectura limita
  los bytes consumidos y normaliza errores de conversión JSON a `NotebookError`.

## Límites y comprobaciones

El álgebra racional no incluye funciones, Float ni coeficientes irracionales:
control previo de ocho símbolos, grado estimado 256 y 4096 términos estimados.
Las sumas tienen 1000 términos por llamada y 2000 compartidos por evaluación.
Los presupuestos no imponen timeout duro ni aislamiento.

Integrales y soluciones pueden seguir condicionadas o no resueltas. Las ramas
Piecewise son alternativas, no requisitos simultáneos. La verificación por
residuos o datos iniciales es local; no demuestra completitud, existencia/
unicidad ni dominio global. No hay sistemas de EDO, EDP, sesiones persistentes
o compatibilidad general con Wolfram Language. Plot mantiene 201 muestras fijas
y puede omitir polos entre ellas.

La [configuración de CI](../../../.github/workflows/ci.yml) contempla pruebas
en Linux y Windows con Python 3.11/3.12 y construcción/verificación del ejecutable
Windows x64. Consulte las [ejecuciones](https://github.com/Stochasticboi/Mathechan/actions)
del commit correspondiente para sus resultados. La configuración por sí sola
no acredita una prueba en Windows limpio ni todas las instalaciones posibles.

Detalles en [el lenguaje](../lenguaje.md),
[la decisión de alcance](../../decisions/002-scientific-operations.md) y
[la comparación](../comparativa.md). Las pruebas son casos verificables, no
validación científica universal ni un benchmark contra otro sistema.
