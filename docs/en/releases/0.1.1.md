# Mathechan 0.1.1 — scientific operations

19 October 2026 · [Español](../../es/versiones/0.1.1.md) ·
[Home](../../../README.en.md) · [Changelog](../../../CHANGELOG.md)

Version 0.1.1 extends the experimental console kernel with nine scientific
operations and fixes to results, domains, and notebooks. SymPy 1.14 remains the
backend and GPL-3.0-or-later the license. The graphical interface remains pending.

## Downloads and use

- [v0.1.1 release and assets](https://github.com/Stochasticboi/Mathechan/releases/tag/v0.1.1).
- [Windows x64 ZIP](https://github.com/Stochasticboi/Mathechan/releases/download/v0.1.1/Mathechan-0.1.1-windows-x64.zip).
- [Source at tag v0.1.1](https://github.com/Stochasticboi/Mathechan/tree/v0.1.1).

Extract the ZIP and open `Mathechan.exe` to start an interactive console.
Arguments run a calculation or export a plot:

```powershell
.\Mathechan.exe 'N[Pi,50]' --json
.\Mathechan.exe 'Sum[n^2,{n,1,10}]'
.\Mathechan.exe 'Solve[x^2==2,x,Reals]'
.\Mathechan.exe 'Plot[Exp[-x^2],{x,-3,3}]' --output gaussian.svg
```

Installing from source requires Python 3.11 or later and
`python -m pip install -e .`. The package exposes the same calculations through
`python -m mathechan`.
The 0.1.0 ZIP retains its original capabilities; changing documentation or
another version's source does not add these functions to it.

## Nine new operations

| Operation | Example | Scope |
|---|---|---|
| `N` | `N[Pi,50]` | Numeric scalar, 1–1000 requested significant digits; Float without rationalization. |
| `Factor` | `Factor[x^2-1]` | Polynomials with rational coefficients over Q. |
| `Together` | `Together[1/x+1/(x+1)]` | Common denominators for rational functions over Q. |
| `Cancel` | `Cancel[(x^2-1)/(x-1)]` | Rational cancellation retaining original exclusions. |
| `Substitute` | `Substitute[x^2+y,x,1/3]` | Exact substitution of a symbol by a finite scalar value. |
| `Sum` | `Sum[n^2,{n,1,10}]` | Finite sum with inclusive integer bounds; result 385. |
| `Integrate` | `Integrate[Exp[-x^2],{x,-Infinity,Infinity}]` | Definite integrals or antiderivatives without an additive constant. |
| `Solve` | `Solve[x^2==2,x,Reals]` | Scalar equation or linear system; solution sets. |
| `DSolve` | `DSolve[{D[y[x],x]==-y[x],y[0]==1},y[x],x]` | One ordinary ODE, order 1 or 2, with optional initial data. |

Lists of up to 64 elements and inert `==` equalities are added, without
assignment. `Solve` defaults to the complex domain and accepts explicit `Reals`;
systems are limited to eight equations and variables. `DSolve` accepts nested
`D` derivatives and derivative data using `Substitute[D[y[x],x],x,0]==value`.

The [scientific notebook](../../../examples/scientific.mchan) stores the nine
operations as source cells without saved results. Opening it never evaluates cells.

## Results and fixes

- `input` separates checked reusable input from display `text`. The imaginary
  constant uses `Sqrt[-1]`; `I` remains a generic symbol. Float approximations
  retain `input: null`.
- Additive `status`, `exact`, and `details` provide diagnostics. `exact` means
  no Float, not complete resolution. Conditional sets, pending integrals,
  Piecewise branches, and unverified residuals remain visible.
- Original division and negative-power exclusions are retained. Substitutions,
  sum terms, and solutions transport or check them within their scope. Plot
  rejects sampled holes and checks exact symbolic endpoints, such as a `Sin[x]`
  denominator at `Pi`.
- Notebooks use UTF-8 and LF; the 2 MB limit covers the same bytes when writing
  and reading, including Windows. Reading bounds bytes consumed and normalizes
  JSON conversion failures to `NotebookError`.

## Limits and checks

Rational algebra excludes functions, Float, and irrational coefficients:
preflight limits are eight symbols, estimated degree 256, and 4096 estimated
terms. Sums allow 1000 terms per call and 2000 shared per evaluation.
These budgets do not provide a hard timeout or isolation.

Integrals and solutions may remain conditional or unresolved. Piecewise branches
are alternatives, not simultaneous requirements. Residual and initial-data checks
are local; they do not establish completeness, existence/uniqueness, or a global
domain. ODE systems, PDEs, persistent sessions, and general Wolfram Language
compatibility are not provided. Plot keeps 201 fixed samples and may miss poles
between them.
